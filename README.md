# Python Code Challenge Project

## Description

This project contains multiple Python programs that solve different programming problems.
Each project focuses on basic algorithms and data structures

The project includes:

* Word frequency tracking
* Weighted average signal filtering
* Pangram checker
* Number machine operations

---

## How it works

Each program solves a specific problem:

* **Word Frequency Tracker** → counts how often words appear in a sentence
* **Weighted Average Filter** → smooths signals using weighted values
* **Pangram Checker** → checks if a sentence contains all letters of the alphabet
* **Number Machine** → reverses numbers, sums digits, and increments digits

---

## How to run

### 1. Clone the repository

```bash
git clone https://github.com/kksambo/sicelo-sambo.git
cd sicelo-sambo
```

---

### 2. Run each project

#### Word Frequency Tracker

```bash
cd project-1
python frequently_used_words.py
```

#### Weighted Average Filter

```bash
cd project-2
python weighted_average.py
```

#### Pangram Checker

```bash
cd project-3
python pangram.py
```

#### Number Machine

```bash
cd project-4
python number_machine.py
```
