## Number Machine

## Description

This project is a simple Python program that performs three operations on a five-digit number.

It reverses the number, calculates the sum of its digits, and creates a new number by adding 1 to each digit.

---

## How it works

* Takes a five-digit number as input
* Uses modulus (`%`) to extract each digit
* Reverses the number without using built-in reverse functions
* Calculates the total sum of all digits
* Adds 1 to each digit (9 becomes 0) to form a new number
