## Pangram Checker

## Description

This project is a simple Python program that checks if a sentence is a **pangram**.

A pangram is a sentence that contains **every letter of the alphabet at least once**.

---

## How it works

* Takes a sentence as input
* Removes spaces and converts text to lowercase
* Converts the text into a set of characters
* Compares it with all letters from the alphabet
* Returns `True` if all letters are present, otherwise `False`

---
